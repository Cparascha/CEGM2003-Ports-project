### CEGM2003 – Ports Project

This project is part of the **CEGM 2003** course and focuses on identifying
functional port areas using AIS vessel data and satellite imagery.
A case study of the **Port of Los Angeles** is conducted using August 2024 AIS data
and optical imagery. **K-means, DBSCAN, and Spectral clustering** are applied to detect
port activities and validated using spatial metrics.
