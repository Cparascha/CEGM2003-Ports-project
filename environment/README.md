## Environment Setup

This project uses a Conda environment to manage all dependencies required to run the notebooks and scripts.  
The environment specification is provided in the `environment.yml` file.

### Create the environment
1. Clone or download this repository.
2. Open a terminal (Anaconda Prompt on Windows) and navigate to the project root directory (where `braided.yml` is located).
3. Create the Conda environment:
   ```bash
   conda env create -f environment.yml
